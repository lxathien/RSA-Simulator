# RSA-Simulator

Website mô phỏng thuật toán RSA bằng Python.

## Công nghệ sử dụng

- Python
- Flask
- HTML
- CSS
- JavaScript

## Cấu trúc project

```text
RSA-Simulator/
├── app.py
├── rsa.py
├── templates/
│   └── index.html
├── static/
│   ├── style.css
│   └── script.js
└── README.md
```

## Cài đặt

Cài Flask:

```bash
pip install flask
```

## Chạy chương trình

```bash
python app.py
```

Sau đó mở địa chỉ http://127.0.0.1:5000 trên trình duyệt.

> Đây là project học tập. Thuật toán RSA được tự cài đặt trong file `rsa.py`;
> không sử dụng project này để bảo vệ dữ liệu thực tế.
